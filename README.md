# TypeScript Assignment

# Task Overview

This project contains solutions to eight TypeScript problems and two technical blog task.

All code in [`solutions.ts`]:

- `multiplyValue`: optional parameters and the nullish operator
- `processInput`: union types and `typeof` narrowing
- `formatCoordinate`: readonly tuples
- `concatenateArrays`: generics with rest parameters
- `Course` and `getPopularCourses`: interfaces and non-mutating filtering
- `pluckValues`: generics with the `keyof`
- `Employee` and `Manager`: classes, inheritance, `protected` and `private`
- `validateAgeAsync`: promises and setTimeout
